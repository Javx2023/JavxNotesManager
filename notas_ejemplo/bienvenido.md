# Bienvenido a JavxNotesManager

Este es tu gestor de notas Markdown con interfaz web.

## Características

- Crear, editar y eliminar notas en formato Markdown
- Frontmatter para metadatos (título, tags, autor, fecha)
- Búsqueda full-text con opción de frase exacta
- Exportación a PDF (individual, múltiple y por búsqueda)

## Formato de una nota

Cada nota usa frontmatter con este formato:

```
---
title: "Título de la nota"
tags: [ "tag1", "tag2" ]
author: "Tu nombre"
date: DD/MM/YYYY
---

Contenido de la nota en Markdown aquí...
```

## Atajos de Markdown

| Sintaxis | Resultado |
|----------|-----------|
| `# Título` | Encabezado H1 |
| `## Subtítulo` | Encabezado H2 |
| `**texto**` | **Negrita** |
| `*texto*` | *Cursiva* |
| `` `código` `` | `Código inline` |

## Consejos

- Usa tags para organizar tus notas por temas
- La búsqueda full-text encuentra palabras en título, contenido y tags
- Puedes exportar una o varias notas a PDF
